Many people want "an AI assistant" but stop at the first step, convinced it must be
complicated. In practice, five parts make up one assistant — and only three of them
are required to begin.

## The five parts

**1. Somewhere to live.** The assistant has to run somewhere: your own computer, or a small
server that stays on. This is what lets it work while you sleep.

**2. The thinking engine (a language model).** The part that understands your request and
drafts the answer. It can be rented from a provider, and the cost tracks how often you use it.

**3. Tools.** The ability to read files, search the web, run commands, or send a message.
Without this, the assistant can only chat.

**4. A channel.** How you reach it: WhatsApp, Telegram, or email. Best to use one you already
use daily, so there is nothing new to learn.

**5. Notes and rules.** What it should remember, and what it should never do. This is what
separates a tidy assistant from a confusing one.

## Required now, add later

Required at the start: somewhere to run it (1), the thinking engine (2), and a channel (4).
Tools (3) can be added gradually, and notes (5) grow with use.

If any of those three is missing, the assistant is not ready for daily work — even if it
looks finished.

## The step people forget

Set aside time for tidying, not just installing. The common experience: installation takes
an hour, but it takes a few days before the results truly match your working habits.
