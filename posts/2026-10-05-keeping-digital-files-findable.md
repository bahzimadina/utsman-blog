Have you ever hunted for one document for half an hour, given up, and written it again?
That is not a skill problem. It is a naming problem.

## The file name decides everything

Most people save files as `report-final-revision2-new.docx`. Three months later, nobody knows
which one is correct. A habit that lasts longer: start the name with the date and the subject.

- `2026-10-05-october-activity-report.pdf`
- `2026-10-03-support-request-letter.pdf`
- `2026-09-28-training-attendance-list.xlsx`

With that pattern, alphabetical order is the same as chronological order. You do not have to
open each file to find the newest one.

## One folder, one kind

Piling everything into a single "Important Documents" folder does not help either. Keep the
number of folders small, but make them clear: `activities`, `letters`, `finance`, `old-archive`.
If you cannot decide where a file belongs, the categories are unclear — not the file.

## Keep finished work separate

Files you no longer use should not sit mixed in with the active ones. Move them to an
`old-archive` folder and note the year. That way, the list of live files stays short.

## Where the assistant helps

The most tiring part of tidying an archive is renaming files one by one and moving them into
the right folder. That is work worth handing over: state the pattern, and the result can be
reviewed in a single pass.

What stays with you: deciding what is still in use and what may be archived. That is a
decision, not a task.
