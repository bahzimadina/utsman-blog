In most community groups the question is no longer "what is an AI assistant" but "when should I actually use one". Fair enough. The tools already sit inside WhatsApp, Telegram, and email that people open every day, so curiosity has turned into a question about habits.

The short answer: use it for work that follows a pattern, do the rest yourself. The difference usually becomes obvious after a few tries.

## Repetitive work: hand it to the machine

Meeting minutes, event reminders, attendance recaps, draft announcements, the shape of the monthly report. They all come back in a similar form, month after month. An assistant can read messy raw notes and turn them into a readable summary in seconds, without rebuilding every sentence from scratch.

The same goes for routine communication. Drafting an announcement for the group, preparing answers to questions that keep coming back, or shrinking a long thread into a few points. The output still needs a human pass, but the starting line already exists.

## Channels and automation that change things

What makes an assistant feel present is not how clever the model is, but where you can reach it. When it lives inside WhatsApp, Telegram, or email that people already use, nobody has to learn a new app. Older volunteers will not install a dedicated tool, but WhatsApp is already in their hands.

Scheduled automation adds another layer. A reminder can be set up once and then run by itself every morning. Protocols like MCP let the assistant touch files, calendars, or notes instead of only chatting into empty space.

## When you should do it yourself

Some work gets worse when it is rushed. A few examples:

- Decisions that affect many people: committee line-ups, activity budget priorities, performance reviews.
- Conversations that need feeling: hearing a resident's complaint, chairing a tense meeting, apologising for a mistake the organisation made.
- Personal data and sensitive matters: keep them inside the meeting room, never paste them into any tool's chat.
- Anything you must defend under your own name in front of members.

Not because the machine cannot write the sentences. What those moments need is not fast text but presence, empathy, and the nerve to decide.

## One guiding question

Before handing a task over, ask one thing: can this job be explained in a single paragraph of instructions? If yes, give it away and spend the saved time elsewhere. If the answer is "it depends who is involved", do it yourself.

One more thing: an assistant can be wrong with total confidence. Read the draft anyway, especially numbers and names. Treat it like an intern who works fast but has not absorbed the context of your organisation yet.

Understood this way, the tool stays useful without making anyone lazy about thinking. 🤝
